# One Word for Your Wi-Fi

Exactly one word describing our Wi-Fi — the funniest and most accurate one wins, and the winning word becomes the sponsor's network name.

`main.ts` (Node 22) writes the word to `/output/entry.txt`:

> Ghosting

Home Wi-Fi doesn't just get slow — it vanishes mid-call, mid-download, mid-game, with no explanation and no goodbye. Exactly like being ghosted.

Run it twice — both runs are byte-identical.
